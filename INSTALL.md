In order to be able to run our MS2 demo, all you will need to do in terms of installations is have ANSITerminal installed, which can be done by simply running "opam install ansiterminal" in the commandline.

How to use the app:
In order to move pieces, provide the algebraic notation for the starting position of a piece and ending position of a piece. Look at our demo video for more details
In order to quit our program, just use "Control + C"
